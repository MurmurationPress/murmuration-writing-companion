# The Low Water Ledger — migration example

This fictional vault is a disposable legacy-structure fixture. Its Book owns a complete `manuscript_order` list; child notes intentionally lack distributed structural properties so **Prepare existing manuscript** can preview their addition.

Open a copy as its own Obsidian vault. Project Readiness should report **Preparation available**. Select **Prepare manuscript**, inspect every proposed property operation, approve only in a disposable copy, and then test **Undo manuscript preparation** immediately.

Preparation should preserve every filename, folder, prose line and `demonstration_note` property. It should remove the Book's legacy array only after all child notes have been written and verified. Undo should restore the original bytes. Reset by deleting the test copy and extracting a fresh one; do not manually bulk-delete properties.
