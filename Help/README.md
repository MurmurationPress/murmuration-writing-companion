# Murmuration Writing Companion Help

Murmuration Writing Companion (MWC) helps you organise a manuscript, connect it to an optional Story World, and review continuity without moving authority out of your Markdown files.

Normally, use MWC controls and ordinary Obsidian wikilinks. You do not need to maintain the Story World schema by hand.

From an installed plugin, open this guide with **Command Palette → Open Help** or **Settings → Murmuration Writing Companion → Help → Open Help**. MWC opens the maintained guide in your browser and does not create a vault note.

## Documentation authority

This Help explains current product behaviour. The property reference is the canonical author-facing schema summary. Files in `docs/` provide deeper feature contracts and maintainer detail; smoke tests and release-validation records are evidence, not ordinary Help. Where old prose conflicts with current runtime and tests, implementation and tests are the final source of truth.
