# The Greywater Signal — prepared example

This is an original, fictional and disposable demonstration vault. A coastal research team investigates an unexpected ecological signal around an abandoned tidal observatory. The minimal prose exists only to make navigation and review views understandable.

## Open safely

1. Copy this entire `prepared-vault` directory somewhere outside your live writing vault.
2. Open the copy as a vault in Obsidian.
3. Install or enable Murmuration Writing Companion using the supported release instructions.
4. Choose **Open project readiness**. It should report one prepared Book, two Parts and five Scenes.

The direct Scene **Opening at Greywater** appears before the two Parts. Filenames have no required numeric prefixes; order comes from each note's `manuscript_order_key` within its sibling group.

The Story World contains two Characters, a Location, an Organisation, a Technology, two dated Events and one Reference. **Tideglass Array** deliberately cites a missing `Uncatalogued Calibration Sheet`; Story World Review should report that explicit unresolved source, and the finding can appear in Continuity Review because Scenes reference Tideglass Array through `world_context`. This is a diagnostic demonstration, not accidental damage.

Generate a vault entity index from **Generate entity index** and choose **Vault**. Reference citation metadata remains on the authoritative Reference note. Open `Story World/References/References.base` or `Reference Projections/References Dataview.md` for native, read-only Obsidian projections. The Base definition is not Markdown, and the Dataview support note deliberately lives outside Story World and Manuscript authority.

## Reset

Delete the disposable copy and make a fresh copy from the release archive. Do not bulk-delete structural properties to reset it. No file outside this vault is read or written by the example itself.
