# Printable entity index

Use **Generate entity index** from the command palette to preview a Markdown index for either the selected recognised Book or every recognised Book in the vault. Book scope starts with the Book selected in the Manuscript Navigator and permits another Book to be chosen. The dialog filters by canonical `world_entity` category; all recognised categories are enabled initially. The preview shows entry, Scene-occurrence and omitted-orphan counts. **Cancel** makes no change. **Save new note** creates `Entity Index - Book Title.md` for Book scope or `Entity Index - Vault.md` for vault scope at the vault root, matching the existing generated-report workflow. The destination remains editable and an existing note is never overwritten.

An occurrence is explicit evidence: a manuscript Scene wikilink that resolves through Obsidian or the existing unique Story World alias fallback, or structured source/support evidence already recognised by manuscript-impact analysis. Several links or aliases resolving to the same authoritative Story World path in one Scene produce one entry reference. Plain-text prose is deliberately absent: treating it as authority would introduce fuzzy, inferred occurrences that the author did not assert.

Book membership, Parts, Scenes and reading order come from the same `parent` and `manuscript_order_key` hierarchy used by the Navigator. Book scope excludes references from other Books. Vault scope walks recognised Books and their Scenes deterministically and adds the Book title to each Scene label. Part titles qualify Scene titles where Parts exist; duplicate direct-Scene titles receive a deterministic filename qualifier. Entries link to canonical Story World notes, Scene references link to authoritative manuscript notes, and aliases never become independent headings. The report begins directly with alphabetical groups because a separate title heading would repeat the filename and report metadata.

The report has `type: generated-report` and `report_type: entity-index`. Generated reports are disposable projections and are excluded from Story World and manuscript indexing, so they cannot become graph, continuity or later index evidence. The report uses Scene references because pagination depends on a future compiler and output format. Direct PDF, EPUB and DOCX integration remains deferred.

Diagnostics count entities omitted for having no selected-Book occurrence, unresolved or malformed explicit evidence, ambiguous aliases, deleted canonical targets and duplicate Scene titles. Orphans remain omitted by default.
