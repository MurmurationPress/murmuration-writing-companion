# Website-facing V2 onboarding summary

Murmuration Writing Companion helps Obsidian authors organise Books, Parts and Scenes while keeping ordinary Markdown as the authority. A quiet Project Readiness check explains what the plugin recognises in a new or existing vault. Existing manuscripts can enter a previewed, transactional and immediately reversible preparation workflow without automatic prose edits, file renaming or folder moves.

Authors may add an optional Story World for characters, locations, organisations, events, relationships and chronology. MWC derives navigators, continuity observations, impact views, graphs and review or publication-support Markdown reports from explicit manuscript and Story World evidence. It does not write fiction automatically, infer canon from unlinked prose or replace the author's files with a second manuscript model.

The V2 example project is fictional, disposable and opened separately from a live vault. Website publication, final screenshots and cross-platform release certification remain part of the release process rather than this source document.
