## Native reproduction and evidence

Run after building:

```sh
node scripts/diagnostics/verify-reading-annotations.mjs /tmp/mwc-reading-evidence.json
```

The replay creates a new synthetic vault and profile under `/tmp`, installs the unmodified production assets, drives native Obsidian through CDP, types through browser input, clicks each action once, gracefully restarts Obsidian, and compares the manuscript files. Source selections use native DOM ranges; the context-menu event is dispatched into the native host and command/shortcut/palette actions use the installed command. No private manuscript is used. The [recorded native evidence](issues-270-259-native.json) includes the verified production bundle hash, environment, anchors, lifecycle/scroll/preference observations and file hashes.

Windows, macOS, mobile, older supported Obsidian versions remain unverified. ## Deliberate limitations

The mapping is conservative. Embeds, fenced code, HTML, mathematics, tables, footnotes, callout headings/complex nested callouts and renderings that differ from the checked prose projection are rejected with a useful notice. Evicted source snapshots also require a fresh render/selection. Any manuscript-body change while composing requires reselection, even when a human could infer the intended passage. These restrictions prevent silently attaching an annotation to the wrong source.

Constitution Articles I–III, VI–VII and IX shaped the implementation: manuscript sovereignty, one portable editorial authority, native Reading view, and failure without incorrect writes. The only new persisted value is a vault-local UI preference; drafts and rendered snapshots remain transient. No editorial schema migration is needed.
